# Avalhla_Characters

CrossWorld canon for identities, aspects, bonds, worlds, doors, crossings, skills, crafts, objects, colors, mappings, and derived views.

The repository is a bounded domain repository. Avalhla Core remains the system/runtime/CoBuilder authority. This repository does not copy `memory/auto-read/00_AI_COBUILD.json`.

## Core laws

- One concept → one canonical name → one canonical artifact.
- Filename is an address, not a second semantic system.
- Canonical records are not cards, scenes, mappings, helper output, or evidence.
- D&D 5e is a mapping language; it does not define CrossWorld canon.
- Dawa remains the human decision boundary.
- AvvA is a bond / living threshold, not an agent or authority.
- Color may express; color does not prove.
- The relation survives the skin.
